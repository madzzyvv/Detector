# Object Tracking

Object Tracking — программа на C++ и OpenCV, которая обнаруживает объект заданного цвета на видео с веб-камеры и отслеживает его перемещение между кадрами: сглаживает координаты, переживает кратковременную потерю объекта и оценивает скорость движения.

## Как это работает

- Захватывается видео с веб-камеры.
- Кадр переводится из цветового пространства BGR в HSV.
- На HSV-изображении строится маска по заданному диапазону цвета.
- Маска очищается от шума с помощью морфологических операций `erode`/`dilate`.
- На очищенной маске ищутся контуры белых областей; выбирается контур с наибольшей площадью, по нему строится рамка вокруг объекта.
- Координаты центра объекта сглаживаются во времени (экспоненциальное скользящее среднее), что убирает дрожание рамки и точки.
- По координатам центра на двух соседних кадрах и времени между ними вычисляется скорость движения объекта (в пикселях в секунду).
- Если объект пропадает из кадра, последняя известная позиция удерживается ещё некоторое время (30 кадров), после чего считается, что объект потерян, и отображение прекращается.

## Зависимости и сборка

- C++20
- OpenCV (установлен через vcpkg)
- Visual Studio (Windows)

Проект собирается как обычное консольное приложение C++ с подключённым OpenCV через vcpkg manifest-режим или интеграцию vcpkg с Visual Studio.

## Запуск

При запуске открывается три окна:

- **Frame** — основное окно: видео с камеры, рамка вокруг найденного объекта, его координаты и скорость движения.
- **CleanMask** — маска после очистки от шума; по ней удобно оценивать, насколько хорошо выделяется объект.
- **Controls** — окно с настройками:
  - шесть трекбаров `H/S/V low` и `H/S/V high` — задают диапазон HSV, то есть цвет, яркость и насыщенность объекта, который нужно захватывать; изменения проще всего отслеживать по окну **CleanMask**;
  - трекбар `KernelSize` — задаёт размер ядра фильтрации шума: большее значение сильнее убирает шум на маске, но при слишком большом значении может "съесть" сам объект, если он небольшой.

При запуске детектор уже настроен на оранжевый цвет и работает без дополнительной настройки — трекбары нужны, чтобы подстроить диапазон под другой цвет объекта или другое освещение.

Для выхода из программы нажмите `q`.

## Ограничения

- **Чувствительность к освещению.** Метод определяет объект по цвету в пространстве HSV. При смене освещения заметнее всего меняются яркость (V) и насыщенность (S) объекта, тогда как тон (H) обычно держится устойчивее. Диапазон, подобранный при одном освещении, может не покрывать объект при другом.
- **Нет идентификации конкретного объекта.** Программа не различает объекты по индивидуальным признакам — она просто ищет контур наибольшей площади в заданном диапазоне цвета. Если в кадре несколько объектов схожего цвета, выбирается самый крупный, а не тот, который отслеживался ранее. Трекбары HSV позволяют вручную сузить диапазон и тем самым исключить посторонний объект, но это не автоматическое решение проблемы.
- **Детектор одноцветный.** Программа ищет только один диапазон HSV за раз; одновременное отслеживание объектов разных цветов не поддерживается.
- **Проверено в ограниченных условиях.** Поведение при быстром движении проверялось на собственной камере автора при хорошем освещении и не вызывало потери объекта; на другой аппаратуре или при более резком движении возможен motion blur, который может повлиять на устойчивость детекции.

## Возможные направления развития

- Замена цветового детектора на нейросетевой (например, через `cv::dnn` и модель в формате ONNX) для устойчивости к освещению и различения объектов по форме/классу, а не только по цвету.
- Отслеживание нескольких объектов одновременно.
- Интеграция с управляемой турелью/роботом: передача координат объекта на внешний контроллер для наведения и слежения — развитие в сторону компьютерного зрения для робототехники.
